# Commitment Pools logo

Use `commitment-pools-logo-black-1024.png` for submission. It includes the gold cursive product name above the selected emperor-penguin/vortex emblem on the product's black background.

- Black-background PNG: 1024 × 1024 pixels, 592,528 bytes.
- Transparent PNG: 1024 × 1024 pixels, 648,385 bytes. Use when a form or designer specifically needs transparency; the gold wordmark is intended for dark backgrounds.

Both files contain the full logo, not a screenshot of the app. The existing Great Vibes font was used directly, and the selected artwork was not regenerated or repainted. The source PNG remains unchanged. The original semi-transparent edge pixels are preserved in the transparent export.

PNG decoding, dimensions, registered font, and background alpha were checked; both exports were visually inspected. A particular submission portal may impose a different size or format, which has not been specified or verified. No submission, deployment or repository push was performed.

`manifest.json` records file sizes and SHA-256 hashes. The export script is `../export-logo.cjs`; it uses the current application's built font asset and the bundled native canvas/PNG tools, without adding app dependencies or overwriting existing exports.
